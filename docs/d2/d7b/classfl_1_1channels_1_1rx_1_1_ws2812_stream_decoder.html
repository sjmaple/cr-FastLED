fl::channels::rx::Ws2812StreamDecoder Class Reference

Detailed Description

Streaming decoder over (rise, fall) capture pairs.

Not thread-safe: the owner feeds it from one context at a time (the DMA ISR during the frame, then the thread after the ISR is masked).
